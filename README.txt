POKIPO 再構築版

1. このフォルダを任意の場所へコピー
2. VS CodeでPOKIPO_rebuildフォルダを開く
3. ターミナルで npm.cmd install
4. npm.cmd run dev
5. http://localhost:3000 を開く

画面:
/          初回入力
/home      トップメニュー
/stamp     スタンプラリー
/knowledge ポッキー豆知識
/progress  進捗
/complete  完了

※ 現在はデモ版のためSupabase/API接続なし。
※ 入力情報はsessionStorage、スタンプはlocalStorageに保存。
